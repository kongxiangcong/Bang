# Bang 通用需求

本文是适合源码仓库保存的需求摘要，不包含个人对话、原始研究案例、账户资料或用户工作区内容。它描述产品目标，不表示这些功能已经实现或通过验收。

## 使用分工与入口

用户围绕问题自然对话，首次显式启用 Bang 后，由独立后台整理每轮已完成的用户消息与模型回答，不再要求用户逐轮提醒。后台理解讨论并增量维护同一专题，整理过程不回注主对话上下文。仍保留手动提交入口；用户手改是可选能力，不是系统工作的前置条件。

Bang 定位为通用思维整理白板，服务于学习、策划、会议、产品讨论和研究等内容。PIM 架构对话只是用于验证整理效果的一个案例，不定义产品工作流。表达形式包括便签、分组、树状结构、思维导图和流程图等，可根据内容和用户意图在同一画布中混合使用。

两个目标入口是：Bang 自有对话界面，以及供其他 agent 在用户指定轮次调用的独立技能或接口。它们应复用相同的专题、轮次、来源、增量更新与手改保护逻辑，不各自产生脱节的图。

广泛接入不同对话来源是目标，不承诺无需集成即可读取任意闭源平台。必须能获授权地取得对话，或由用户导入可取得的原文；具体协议、平台兼容性和部署方式尚待验证。

## 画布如何演进

专题独立管理，可以从空白开始或接续已有理解。提交一轮后保留原文，再局部增加、修正或归并相关内容；没有新理解时，允许只保存原文而不改图。不要为每条消息生成节点，也不要每轮重画整张图。

概念可以先散放、不连线。根据实际含义选择结构、流程、依赖、问题或决策等局部表达，不强制某种图类型或系统架构模板。用户可以深入模块子图，再返回主线；层级表达讨论范围，连线表达概念关系，不混成严格树。

用户可以指定表达形式，也可以让 Bang 自动选择，并针对选中的区域重新组织。分类、发散与执行顺序应选择合适的表达，不能把所有关系都画成树或流程。默认忠实整理已有内容；按用户要求补充新想法时，应区分新增建议和原文已有信息。

组织顺序是先识别这次讨论想弄清的问题，再识别内容之间的关系，最后选择或混合表达；不以前置模板选择定义讨论。图上文字可以精简，但完整文字解释、推导步骤、成立条件与来源依据必须可回看。局部更新与撤销应让图形内容和解释依据保持一致，不能只恢复图形而留下另一版本的结论。

默认保留对话为主的体验，由模型静默维护节点短说明，原文按需查看。长总结不作为每轮必做流程。图可以随理解逐渐复杂；新关系用短暂、局部的动效提示，不全图反复重排或持续闪烁，用户操作优先。

## 来源、不确定性与用户修改

原始回答中的说法不能因为被画进图就变成事实。保留来源和条件，区分原文声称、待核实内容与模型推断；矛盾双方应可回看，不因某段回答更晚就自动采信。

后续讨论明确否定旧结论时，复用原节点标为已否定，或移除过时节点及失效关系；旧推导与否定依据留在记录中，不为每次修正新增连线。尚未解决的争议保留为未决，不当作已经否定。

用户可以修改文字和布局，修改进入后续讨论依据，不能静默丢失。具体冲突策略、版本恢复和确认方式尚待决定；原型中个别分支的行为不等于已经选定产品策略。

用户看到的是连续讨论体验，不拆成导师与记录员两种职责。Bang 具有自己的组织和维护能力；讨论技能可以被调用或借鉴，不要求通过开发某个讨论技能来实现整个产品。

## 独立持久工作区

目标是独立于程序源码、可配置并持久保存数据的工作区，统一管理专题、轮次原文、图、来源关联和用户修改。两个入口共用同一工作区。具体路径、目录结构、文件格式、数据库及多用户能力尚未确定。

访问范围、向模型或外部 agent 发送的内容、敏感信息处理和备份去向应明确，不默认暴露整个工作区或无关专题。应能备份和恢复原文、图及其关联并继续讨论，而不仅保存图片；具体权限、备份、加密、同步和迁移方案仍待验证。

## 当前原型与待开发范围

Bang 以对话框中的技能入口启动与继续。当前对话模型负责理解讨论目标、推导与关系，向同一持久白板提交语义增量；白板渲染器不承担关键词猜测或固定模板选择。技能读取实际手改后的对象及来源，新证据与手改冲突时保留当前内容并提供可采用的更新建议。

回放环境按原始用户/模型消息逐条显示，默认每两轮完整问答提交一次整理，最后不足两轮也收尾。回放后的新对话通过同一技能提交路径继续更新，不新建示例白板；已有位置、解释和来源随局部变更与撤销保持一致。

当前实现已支持本地 PIM 分批回放、技能 CLI 提交语义增量、手改冲突建议、同一场景撤销与保存恢复。开放式语义整理由调用技能的当前模型负责；尚未独立评测其质量。多专题管理、宿主插件安装包装、跨设备工作区及可靠文件备份仍待开发。

独立后台原型已验证：初始化复制必要源码到当前项目 `.bang/runtime`，只读取绑定聊天的完成轮记录，调用独立 Codex 进程整理到 `.bang/topics/<topic>`；专题白板自动显示已提交版本。浏览器关闭不影响语义整理落盘。目前使用本机 transcript 格式轮询，未接通宿主 hook；需显式提供聊天记录及模型执行入口，未实现技能自动发现、全局安装或开机自启。

下一步应先检验一条最小可交互体验及其更新约束，再接真实对话的窄闭环，用实际反馈决定扩展范围。源码仓库的建立与克隆不意味着已经部署、启动服务或批准完整生产实现。
