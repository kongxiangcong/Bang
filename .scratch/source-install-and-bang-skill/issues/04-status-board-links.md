# 04: 查看各专题白板与进度，保持停采边界

Status: resolved

**What to build:** 用户在宿主对话输入 `$bang status` 就能看到整个项目并打开各专题。主动停止后同一入口仍可用于回看。

**Blocked by:** [01 安装一次，在新目录记录第一轮](01-install-first-turn.md)、[02 主动停止项目，结束所有采集区间](02-stop-capture.md)

- [x] 在空目录查询仅报告尚未初始化，目录中没有新增项目文件。
- [x] 在有三个专题的项目，从未绑定会话查询，逐行显示专题名、各自的链接、采集会话、原文轮数和最近成功整理进度；无需选择专题。逐个核对链接目标，过期后可重新查询取得新链接。
- [x] 保存三轮，其中两轮正文相同。修订第二轮并重投同一版后仍显示三轮，两版原文均可回读；只计入实际成功的整理进度。
- [x] 通过宿主输入 `$bang stop`，再用 `$bang status` 启动白板服务。回执显示当前无会话正在采集，已有白板可打开；继续聊天后再次查询，轮数保持原值。

四项专项测试通过。一次未使用的链接在 60 秒后返回 401，重新查询取得 303 并指向原专题。真实 GDN 会话停采后的查询返回新链接，保留十轮原文与最近成功整理进度。[宿主回执](../validation/live-gdn-nNjIVB/stop-and-reopen.json)
