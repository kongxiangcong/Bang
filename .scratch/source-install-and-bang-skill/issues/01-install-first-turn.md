# 01: 安装一次，在新目录记录第一轮

Status: resolved

**What to build:** 用户从源码安装一次后，能在不同学习目录的 Codex 对话里用 `$bang` 开始记录。

**Blocked by:** None (can start immediately)

- [x] 在两个独立的新目录调用同一个用户级技能，各自按目录名创建专题并绑定当前会话，无需在 shell 配置短命令。
- [x] 回执给出当前专题的一次性链接，由用户自行打开。即使用户说“打开白板”，技能也只打印链接。
- [x] 监听生效后才显示“正在自动记录”。未配置整理模型时说明配置状态，完成一轮专题讨论后能回读对应 Episode；配置模型后该轮可参与整理。
- [x] 重跑安装可刷新已安装入口；遇到用户自行编写的同名技能，保留其原文。

## Comments

真实 Codex 在隔离的 `gdn` 和 `linear-attention` 目录分别调用同一已安装技能。两个链接各自指向同名专题。未配置模型时各保存一轮，Episode 与宿主问答逐字一致。安装回归测试也覆盖补配模型后的整理，以及用户自写或修改的技能保护。[真实双目录证据](../validation/codex-two-projects.json)
