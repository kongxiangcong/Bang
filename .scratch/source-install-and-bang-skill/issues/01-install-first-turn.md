# 01: 安装一次，在新目录记录第一轮

Status: ready-for-agent

**What to build:** 用户从源码安装一次后，能在不同学习目录的 Codex 对话里用 `$bang` 开始记录。

**Blocked by:** None (can start immediately)

- [ ] 在两个独立的新目录调用同一个用户级技能，各自按目录名创建专题并绑定当前会话，无需在 shell 配置短命令。
- [ ] 回执给出当前专题的一次性链接，由用户自行打开。即使用户说“打开白板”，技能也只打印链接。
- [ ] 监听生效后才显示“正在自动记录”。未配置整理模型时说明配置状态，完成一轮专题讨论后能回读对应 Episode；配置模型后该轮可参与整理。
- [ ] 重跑安装可刷新已安装入口；遇到用户自行编写的同名技能，保留其原文。
