# 03: 在已有项目选择专题，接续多个会话

Status: resolved

**What to build:** 会话进入已有项目时按用户意图选择专题；打开第二个会话继续讨论时，第一个会话仍保持绑定。

**Blocked by:** [01 安装一次，在新目录记录第一轮](01-install-first-turn.md)

- [x] 重复调用沿用当前绑定和原采集区间。未绑定会话可以点名专题；未点名且只有一个活跃专题时直接绑定。
- [x] 多个活跃专题且目标未明确时列出候选，选定前保持未绑定，再按新绑定起点采集。
- [x] A、B 同时绑定一个专题，回执列出两者，两边的新问答均能回读；显式解绑 A 后，只有 B 继续采集。
