# 02: 主动停止项目，结束所有采集区间

Status: ready-for-agent

**What to build:** 用户通过现有项目停止入口结束本项目全部采集，保留白板和历史。遵循 ADR 0001，意外退出仍可从有效绑定续采。

**Blocked by:** None (can start immediately)

- [ ] 在项目内绑定多个会话并覆盖不同专题。收到停止请求时，A 已完成但仍未读取的一轮可以回读，B 当时尚在生成的一轮随后完成也跳过。
- [ ] 原文保存后即可停止后台，无需等待模型整理。另一项目继续记录；停止项目的各会话在停采期间均无新增 Episode。
- [ ] 一条来源暂时不可读时仍结束全部绑定，回执点名未能核实尾部的会话。恢复来源后，仅可补入能证明在停止前已完成且符合采集规则的问答。
- [ ] 停止后只重新绑定 B，只有 B 从新起点开始记录。另模拟进程意外退出，确认原有效绑定恢复并补齐期间问答。
