# 05: 手动更新源码，保住正在记录的项目

Status: resolved

**What to build:** 用户自行更新源码并重跑安装脚本，正在记录的项目可以继续讨论，新启动的项目使用更新后的版本。

**Blocked by:** [01 安装一次，在新目录记录第一轮](01-install-first-turn.md)

- [x] 在项目 A 已绑定并保存一轮后更新源码、重跑安装。A 仍使用原版本与原绑定，更新期间的有效问答可回读。
- [x] 更新后启动项目 B，通过宿主调用新版。A 下次启动时也采用新版。
- [x] 在安装过程中制造一次失败，从原有入口再次调用技能，确认仍能访问此前可用的项目。

## Comments

隔离安装测试验证旧项目贯穿更新保持原运行版本和原采集区间，新项目和重启后的原项目采用新版。注入安装校验失败后，原入口仍能绑定并访问原专题。两项测试也验证能捕获相应的变异回归。
