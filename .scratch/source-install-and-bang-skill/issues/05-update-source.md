# 05: 手动更新源码，保住正在记录的项目

Status: ready-for-agent

**What to build:** 用户自行更新源码并重跑安装脚本，正在记录的项目可以继续讨论，新启动的项目使用更新后的版本。

**Blocked by:** [01 安装一次，在新目录记录第一轮](01-install-first-turn.md)

- [ ] 在项目 A 已绑定并保存一轮后更新源码、重跑安装。A 仍使用原版本与原绑定，更新期间的有效问答可回读。
- [ ] 更新后启动项目 B，通过宿主调用新版。A 下次启动时也采用新版。
- [ ] 在安装过程中制造一次失败，从原有入口再次调用技能，确认仍能访问此前可用的项目。
