# 05: 自动同步、失败隔离与恢复

Status: ready-for-agent

**What to build:** 用户可查看队列、立即同步并重试失败会话，其他会话持续更新。

**Blocked by:** [04 跨会话归并、来源撤回与语义门禁](04-semantic-gate.md)

- [ ] 分别通过累计约 4–6 轮、静默 90 秒及手动同步触发整理，公开状态可查，重复投递不增加计数。
- [ ] 制造一次会话级失败，核对退避、失败状态和显式重试；其他会话照常提交。Pass 2 可从已保存的会话子图续跑。
- [ ] 关闭浏览器后仍能完成作业；守护进程中断再启动可接续未完成工作，不重复提交版本。
