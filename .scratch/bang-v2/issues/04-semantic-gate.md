# 04: 跨会话归并、来源撤回与语义门禁

Status: ready-for-agent

**What to build:** 在另一会话继续讨论时，用户可查当前结论、历史判断、冲突双方和依据。

**Blocked by:** [02 两层整理引擎与 GDN 总结](02-gdn-reasoning.md)

- [ ] 复用 02 的子图与算子契约。全局索引与局部召回涵盖争议及近期被替代节点；跨会话补证、限定、替代、闭合问题和更新个人认知后，可用 inspect 区分各状态。
- [ ] 使用独立多会话学习及架构讨论材料验证。Q05/Q17/Q20 先保存旧来源再更新，原文历史可查，当前判断停止使用已撤回前提。
- [ ] 提供最小公开字段修改入口及写入保护。Q09 从周五开始，经该入口实际保存为下周二，随后同步新增测试项，核对日期与新增项。
- [ ] Gate 2：立即运行 Q01–Q13、Q16–Q20，每案三轮共 54 次，保留全部结果与错误，按冻结规则独立评分。缺跑或出错、丢失手改、编造来源、沿用撤回前提均阻断通过；各适用维度无 0 分且均值至少 1.8。保存可复核的评测记录后方可进入重交互开发。
