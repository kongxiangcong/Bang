# Bang bundle

用户调用此技能即启用当前项目和当前聊天的 Bang 整理。项目数据保存在 `.bang/`。完成轮问答与相关白板上下文会发送给独立 Codex 整理器并使用现有模型额度。

使用下列 JSON 数组作为可执行文件和参数，最后追加目标项目的绝对路径作为一个独立参数。在项目目录执行，保留宿主提供的当前聊天环境。

```json
@@BANG_COMMAND@@
```

Windows 如果返回 `BANG_WINDOWS_HOST_ACCESS`，独立整理器继承了当前工具的受限身份，无法在已登录的 Codex 主目录初始化。在宿主支持时，用工具的正常命令权限申请流程请求批准原样重跑这一条命令。只请求本次初始化的权限，保留整理器的独立、只读、无工具执行方式。若宿主拒绝或不提供该能力，报告原因。

`initialized: true` 时返回 `whiteboardUrl` 和 `organizerEnabled`。用户继续正常聊天即可，整理器在可核验的完成轮之后运行。刚启动时只能报告绑定和后台状态。只有对应来源和白板提交可核验时才能报告已整理。

同一聊天重复调用沿用现有进度。在同一项目的新聊天调用可接续原专题。遇到 `selection-required` 时请用户选择专题，再传 `--topic <id>`。遇到其他连接器占用专题、宿主无法提供会话身份或独立整理器暂停时，报告具体状态。不要猜测聊天 ID、修改宿主信任或补录其他聊天。
