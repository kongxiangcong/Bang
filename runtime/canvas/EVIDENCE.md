# Evidence validity — ticket 20

The common prepared-intent publisher marks affected committed knowledge `metadata.basis.status = "needs-review"` in the same revision as a semantic change, deletion, import or compensation undo. The recorded dependency closure propagates transitively. Organizer currently records its whole read subgraph, so propagation is deliberately conservative; it does not infer support from arbitrary edge labels. Original bodies, role, geometry, sources, conditions and uncertainty remain in committed/history state. Changed sourced wording no longer receives implicit support from the former references. Pure geometry and visual membership do not withdraw evidence. Structure remains a semantic reasoning dependency.

Read dependencies include semantic field versions, a persistent semantic-change revision (including imports), basis state and knowledge metadata. Thus an in-flight result writing elsewhere is rejected after premise change, even after edit-away-and-back. Proposal adoption retains ticket 19 rejection/reconsideration and manual authorization protections and now checks basis/semantic revisions too. Model output cannot clear validity, choose review operations, or rewrite a withdrawn card.

`knowledge-context --project DIR --topic ID` and protected GET `/api/canvas/:topic/knowledge-context` return revision, usable cards/relations/metadata and a withdrawn identity/status index. The same projection supplies Organizer active context, bounded to 100 cards there. Withdrawn content and historical review sources are excluded from that usable projection; full originals remain available via explicit state/history reads. Review history is not new independent model evidence. This is the public read contract for future ContextBridge delivery; ticket 20 does not claim automatic real-host delivery.

Explicit `basis-review` CLI JSON stdin / protected POST accepts `{operationId,baseRevision,id,dependencies,note,authorId}`. It requires the current complete baseline, a nonempty human note and existing usable knowledge dependencies. It commits through the same publisher, preserves the body, archives the old evidence and records the selected dependencies with an empty current discussion-support list. A review declares current human reasoning, never empirical truth; conditions and uncertainty remain. Repeated operation identity is idempotent. Further semantic changes require review again. Review creates no source authority and no model call. The editor shows affected identities, historical evidence, explicit current-dependency selection, the review receipt and manual-refresh boundary, separately from the body/role/layout.

No new persistent tables: validity, audit and semantic revisions are part of the existing committed snapshots. Complete backup/restore retains them; existing organizer/proposal/source authority freezing remains unchanged. Missing precise dependency information is handled by the recorded conservative read subgraph, not guessed causal links.
